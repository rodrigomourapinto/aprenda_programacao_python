# Aprenda Programação Python

Bem-vindo à Wiki completa do repositório **Aprenda Programação Python**.

Este repositório e esta documentação englobam desde os fundamentos absolutos até os conceitos avançados de Inteligência Artificial para programadores.

> [!NOTE]
> Você pode navegar pelos **21 módulos** do curso completo utilizando o menu lateral (Sidebar) desta Wiki.

## Estrutura do Curso

A jornada de aprendizado está dividida em 21 grandes módulos:

1. **Começando**: Introdução ao mundo Python, sintaxe e variáveis.
2. **Mão na Massa com Python**: IDEs, estruturas de controle e laços de repetição.
3. **String em Python**: Manipulação profunda de textos e strings.
4. **Listas**: Trabalhando com estruturas de dados mutáveis e ordenadas.
5. **Tuplas**: Estruturas de dados somente-leitura.
6. **Pares Chave-Valor**: Dicionários e mapeamentos.
7. **Conjuntos**: Sets e operações de conjuntos matemáticos.
8. **Funções**: Reutilização de código, escopo e lambdas.
9. **Projeto Um - Caixa**: Projeto prático de um supermercado.
10. **Manipulação de Arquivos**: Lendo e escrevendo dados persistentes.
11. **Tratamento de Exceções**: Como lidar com erros de forma elegante.
12. **Módulos**: Organizando código em vários arquivos.
13. **Programação Orientada a Objetos**: Classes, objetos e princípios POO.
14. **Multithreading**: Executando tarefas simultâneas.
15. **Projeto Dois - Biblioteca**: Aplicativo de gerenciamento completo.
16. **Conectividade com Banco de Dados**: MySQL e SQL.
17. **GUI**: Interfaces Gráficas com Tkinter.
18. **Projeto Três - CRUD**: Criando um aplicativo funcional com banco de dados e interface.
19. **Preparação para Entrevista Python**: Revise todos os conceitos.
20. **Essenciais de IA para Programadores**: Fundamentos de Inteligência Artificial.
21. **Aprimorando a Programação com IA**: Usando IA no VS Code para maior eficiência.

Utilize o Índice lateral para começar seus estudos!
